# 服务部署手册

本手册说明 order-service 的部署、验证与回滚流程，适用于预发和生产环境。

## 服务端口

服务默认监听 8080 端口，可通过环境变量 PORT 覆盖；负载均衡器的健康检查也指向该端口。

## 环境准备

### 依赖安装

使用 Python 3.11，执行 `uv sync --locked` 安装依赖。

## 发布流程

1. 合并到 main 分支后，CI 自动构建镜像。
2. 在发布平台选择镜像版本，发布到生产集群。

## 灰度发布

先发布 5% 的实例并观察 30 分钟，错误率没有上升再逐步放量到 100%。

## 上线验证

### 健康检查

部署完成后访问 /healthz，返回 200 即表示进程已就绪。

## 监控告警

接口错误率超过 2% 并持续 3 分钟时，触发电话告警；阈值已由 SRE 复核。
